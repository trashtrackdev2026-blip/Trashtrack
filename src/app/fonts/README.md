These Latin variable fonts (weights 100–900) are the Inter and Outfit WOFF2
files already used by the admin's Next.js Google Fonts build. They are kept
locally so builds and development startup do not download fonts. Next.js still
preloads and serves them from the admin server with `font-display: swap`.
